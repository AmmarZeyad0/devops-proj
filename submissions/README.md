# Submissions

Where you turn in the evidence for each week — command output, screenshots, write-ups, anything
the checklist in `weekly_progress/week-XX/` asks you to produce.

Code and config that are part of the project itself (your app, your manifests, later your
pipeline and Terraform) live in their real homes (`app/`, `k8s/`, …), not here. This folder is
for **proof it works** and **your explanations**.

Each week gets its own `week-XX/` folder. Put your files there, then reference them in your PR
description (see the "Submission" section of that week's checklist for what the PR itself should
look like).
